DEFEND YOUR BULLSHIT.

一个荒谬项目。三轮教授质疑。你唯一的武器是学术语言。目标不是证明项目有用，而是让它看起来无法被轻易否定。

HOW TO PLAY / 怎么通关
  1. 选择建筑包体，输入或随机抽一个项目。
  2. 生成概念陈述，然后进入三轮答辩。
  3. 每轮选择策略，或写自己的回答。自由输入会被本地规则检测关键词、证据、概念堆叠和回避程度。
  4. 通关需要：Conceptual Depth >= 8，Academic Confidence >= 8，Actual Substance >= 4，并且 Committee Discomfort 保持在 4-15。
  5. 不适值首次达到 10 会触发现实 Battle；概念受到欣赏或随机追问也可能触发。限时拼贴单词会改变评分，可以暂停计时。
  6. 太实证会让委员会不安；太概念会显得空；太诚实会被误读成激进反思；删掉设计有时反而会被夸。
随机事件 / 什么时候会发生？
  • 不适值首次达到 10：必定触发限时磁条 Battle。
  • 本轮概念得分达到 6：35% 概率触发欣赏型 Battle；否则还有 12% 概率突发 Battle。
  • 第 2、3 轮：12% 概率评委去开会；第 3 轮另有 15% 概率评委下班。
  • 每轮：8% 概率空降 visiting critic；累计概念深度达到 8 时升为 18%。每轮最多换席一次。
  • Battle 中 CHAOS 达到 7：教授暂时离席倒水，倒计时继续。

评委名字由建筑大师名字拼贴并故意错拼，都是虚构角色。换席保留已有分数，新评委会带来新的偏好和问题。

目前只有建筑包体。欢迎加入新的学科包体。

默认会尝试免 key 公共文本接口，让微信里也能有更随机的教授反馈。免费接口可能慢或失败，失败时自动回到本地规则引擎。

可以本地导入奇葩教授包体 JSON 试玩。社区提交仍建议走 GitHub pull request，避免上传真实姓名或真实机构。

这是本地模板与规则引擎，不是实时 AI 生成。你可以输入自己的建筑概念继续玩，但系统理解能力有限，会用可解释的关键词规则评分。
